# ==============================================================================
#   REMOVE ANY ENTITY - pick what should stop spawning
# ==============================================================================
#
#   Every line below starts with  #  which means "off" (it spawns as normal).
#   To REMOVE something from the game, delete the  #  at the start of its line.
#
#     #animalZombieDog        <- still spawns
#     animalZombieDog         <- removed
#
#   Save the file, then type  rae reload  in the server console (F1 in single
#   player) to apply it straight away. Restarting works too.
#   Or skip the file:  rae remove zombieScreamer  /  rae keep zombieScreamer
#
#   A name removes ALL its versions: "zombieScreamer" also removes the Feral,
#   Radiated, Charged and Infernal screamers. To remove only one version, add its
#   full name on its own line, e.g.  zombieScreamerRadiated
#
#   Only in some biomes: add "in" and the biomes. This stops coyotes spawning in
#   the open world of the desert and wasteland, but not anywhere else:
#     animalCoyote in desert, wasteland
#   Biomes: pine_forest (or forest), burnt_forest (or burnt), desert, snow,
#   wasteland. Sleepers in buildings and hordes aren't tied to a biome, so a
#   biome line doesn't change them.  Console:  rae remove animalCoyote in desert
#
#   Swap one creature for another: write  ->  and the one to spawn instead.
#   It keeps the same chance, so zombie dogs become wolves one for one:
#     animalZombieDog -> animalWolf
#   Console:  rae replace animalZombieDog animalWolf
#   rae keep <name>  undoes any of these.
#
#   Creatures already out stay until they die. To clear them now, type
#     rae cull          (despawns them in the loaded areas; rae cull count  only counts)
#
#   Names from other mods work too: add them on their own line.
#   Type  rae  in the server console to see what was removed.
#
#   Only natural spawns change: biomes, buildings (sleepers), wandering hordes,
#   blood moon hordes, screamer scouts and Twitch spawns. Things that are
#   already in the world stay, and admins can still spawn anything by hand.
