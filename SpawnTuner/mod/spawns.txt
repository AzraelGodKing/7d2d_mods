# ==============================================================================
#   SPAWN TUNER - spawn rates you can change while the game runs
# ==============================================================================
#
#   Easiest: change these from the server console (F1 in single player), e.g.
#     spawns NightDensity 4
#     spawns refresh
#   The console saves your change to this file. You can also edit the file and
#   type  spawns reload
#
#   A line that starts with # is ignored, and that setting comes from the
#   world's own settings (the sandbox options you picked when you made it).
#
#   Density = how many enemies (or animals) each spawn spot in an area can hold
#             none, default, or a number (the game's own range is 1 to 5)
#   Respawn = how fast an area refills after it empties
#             default, veryslow, slow, normal, fast, veryfast
#
#   Percent = 100% is vanilla, 200% is double, 0% turns it off
#
#   New settings apply as each area's timer runs out, which can take a few game
#   days. Type  spawns refresh  to restart the timers in the loaded areas now.
#
#   Ramps: a "Ramp.<setting>" line moves a setting as the game days pass,
#   starting from the value above it (or the world's value). For example
#     Ramp.NightDensity = +1 every 7 days max 8
#   adds 1 on day 8, 2 on day 15, and so on, never above 8. Use a minus to go
#   down. Console:  spawns ramp NightDensity +1 every 7 max 8
#
#   Presets: the presets folder holds whole sets of settings.
#     spawns save <name>   saves every change here as a preset
#     spawns load <name>   switches to a preset (chill and hard come with the mod)
