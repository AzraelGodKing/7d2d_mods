# Upgrade Bench - mod upgrades
#
# Put TWO of the same mod below, at the SAME quality, in the Upgrade Bench. It shows the extra materials needed;
# press the button and both mods plus the materials are used up, and ONE mod comes back a quality level higher
# (up to Q6). The materials are taken from your backpack/toolbelt.
#
# This file is read by each PLAYER's game (the upgrade happens on their PC), so after changing it, give players
# the updated mod folder. Restart the game after editing. Typos in item names are reported in the game log.
#
# Laid out like the "Upgradable weapon mods & potential upgrade costs" sheet:
#
#   <mod name> = <recipe item #1> or <#2> or <#3> : <item amounts> : <iron/steel amounts>
#                  (columns D, E, F)                  (I, K, M, O, Q)  (J, L, N, P, R)
#
# Each upgrade costs: 2 of the mod (same quality), plus the item amount of ANY ONE of the recipe items
# (whichever you have enough of), plus the iron/steel amount. Amounts are listed in order: Q1->2, Q2->3, Q3->4, Q4->5, Q5->6.
#
# Which metal (columns G and H):
Iron  = resourceForgedIron     # upgrades to Q2 and Q3
Steel = resourceForgedSteel    # upgrades to Q4, Q5 and Q6
